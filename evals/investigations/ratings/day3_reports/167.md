### Suggestive

#### F3 · The churn spike is concentrated in a specific plan tier (particularly 'starter') or acquisition channel (e.g. 'paid_social') that grew disproportionately in recent cohorts and has structurally higher churn, making Q2 2026 look worse due to mix shift.

- **Claim:** `logo_churn_rate` is **higher** for plan_tier = `starter` · dimensions: `plan_tier`, `channel`, `month`
- `h3.c1` → **confirmed** (badge `clean`): `churn_rate` (plan_tier=starter) = **0.0493**; `active_accounts` (plan_tier=starter) = **6,860**; `churn_rate` (plan_tier=__rest__) = **0.0307**; `active_accounts` (plan_tier=__rest__) = **10,608**; `rel_diff(churn_rate)` = **+60%**
- `h3.c2` → **refuted** (badge `clean`): `account_share` (plan_tier=starter, month=>= 2026-04-01) = **0.378**; `account_count` (plan_tier=starter, month=>= 2026-04-01) = **2,197**; `account_share` (plan_tier=starter, month=< 2026-04-01) = **0.393**; `account_count` (plan_tier=starter, month=< 2026-04-01) = **4,325**; `rel_diff(account_share)` = **-4%**
- `h3.c3` → **confirmed** (badge `clean`): `churn_rate` (channel=paid_social) = **0.15**; `active_accounts` (channel=paid_social) = **712**; `churn_rate` (channel=__rest__) = **0.116**; `active_accounts` (channel=__rest__) = **3,684**; `rel_diff(churn_rate)` = **+29%**

<details><summary>SQL behind this finding</summary>

```sql
SELECT
    month,
    plan_tier,
    CAST(SUM(CASE WHEN is_churn_month = TRUE THEN 1 ELSE 0 END) AS DOUBLE)
        / NULLIF(COUNT(*), 0) AS churn_rate,
    COUNT(*) AS active_accounts,
    SUM(CASE WHEN is_churn_month = TRUE THEN 1 ELSE 0 END) AS churned_accounts
FROM saasco_marts.mart_account_months
WHERE month >= DATE '2025-10-01'
  AND month <= DATE '2026-06-01'
  AND plan_tier IN ('starter', 'growth', 'pro')
GROUP BY month, plan_tier
ORDER BY month, plan_tier
```

```sql
WITH active_accounts AS (
    SELECT
        month,
        plan_tier,
        COUNT(account_id) AS account_count
    FROM saasco_marts.mart_account_months
    WHERE month BETWEEN DATE '2025-10-01' AND DATE '2026-06-01'
      AND is_churn_month = FALSE
    GROUP BY month, plan_tier
),
monthly_totals AS (
    SELECT
        month,
        SUM(account_count) AS total_account_count
    FROM active_accounts
    GROUP BY month
)
SELECT
    a.month,
    a.plan_tier,
    a.account_count,
    ROUND(a.account_count * 1.0 / m.total_account_count, 4) AS account_share
FROM active_accounts AS a
JOIN monthly_totals AS m ON a.month = m.month
ORDER BY a.month, a.plan_tier
```

```sql
SELECT
    CASE
        WHEN month BETWEEN DATE '2026-01-01' AND DATE '2026-03-01' THEN 'Q1 2026'
        WHEN month BETWEEN DATE '2026-04-01' AND DATE '2026-06-01' THEN 'Q2 2026'
    END AS quarter,

ORDER BY quarter, channel
```

<details><summary>SQL behind this finding</summary>

```sql
WITH churn_q2 AS (
    SELECT
        cohort_month,
        COUNT(DISTINCT account_id) AS churned_accounts
    FROM saasco_marts.mart_account_months
    WHERE is_churn_month = TRUE
      AND month >= DATE '2026-04-01'
      AND month <= DATE '2026-06-01'
    GROUP BY cohort_month
),
cohort_totals AS (
    SELECT
        cohort_month,
        COUNT(DISTINCT account_id) AS total_accounts_in_cohort
    FROM saasco_marts.mart_account_months
    GROUP BY cohort_month
)
SELECT
    ct.cohort_month,
    ct.total_accounts_in_cohort,
    COALESCE(cq.churned_accounts, 0) AS churned_accounts
FROM cohort_totals AS ct
LEFT JOIN churn_q2 AS cq
    ON ct.cohort_month = cq.cohort_month
ORDER BY ct.cohort_month
```

```sql
SELECT
    CASE
        WHEN month >= DATE '2026-01-01' AND month <= DATE '2026-03-01' THEN 'Q1 2026'
        WHEN month >= DATE '2026-04-01' AND month <= DATE '2026-06-01' THEN 'Q2 2026'
    END AS quarter,
    CASE
        WHEN tenure_month BETWEEN 1 AND 6   THEN '1-6'
        WHEN tenure_month BETWEEN 7 AND 12  THEN '7-12'
        WHEN tenure_month BETWEEN 13 AND 24 THEN '13-24'
        WHEN tenure_month >= 25             THEN '25+'
    END AS tenure_bucket,
    COUNT(*) AS active_accounts,

        4
    ) AS churn_rate
FROM saasco_marts.mart_account_months
WHERE
    (month >= DATE '2026-01-01' AND month <= DATE '2026-03-01')

GROUP BY
    quarter,
    tenure_bucket
ORDER BY
    quarter,
    CASE tenure_bucket
        WHEN '1-6'   THEN 1
        WHEN '7-12'  THEN 2
        WHEN '13-24' THEN 3
        WHEN '25+'   THEN 4
    END
```
