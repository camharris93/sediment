- `h1.c2` → **confirmed** (badge `clean`): `revenue_churn_rate` (month=>= 2026-01-01) = **0.0341**; `starting_mrr` (month=>= 2026-01-01) = **16,337,571**; `revenue_churn_rate` (month=< 2026-01-01) = **0.0149**; `starting_mrr` (month=< 2026-01-01) = **21,721,444**; `rel_diff(revenue_churn_rate)` = **+129%**
- Skeptic `mix_shift` on `plan_tier` → **passed**: `raw_change` = **0.0201**; `mix_standardized_change` = **0.0205**; `share_of_change_kept` = **1.019**; `share_of_change_removed` = **-0.019**

- Skeptic `mix_shift` on `cohort_month` → **passed**: `raw_change` = **0.0212**; `mix_standardized_change` = **0.0188**; `share_of_change_kept` = **0.887**; `share_of_change_removed` = **0.113**

### Refuted

#### F2 · Early churn (churn within # days of start) spiked for cohorts that started in late 2025 / early 2026, driven by a specific plan tier or acquisition channel acquiring lower-fit customers.

- **Claim:** `early_churn_rate` is **higher** for cohort_month = `2025-10..2026-06` · dimensions: `cohort_month`, `plan_tier`, `channel`
- `h2.c1` → **suggestive** (badge `clean`): `early_churn_rate` (cohort_month=>= 2026-01-01) = **0.0935**; `n_subscriptions` (cohort_month=>= 2026-01-01) = **674**; `early_churn_rate` (cohort_month=< 2026-01-01) = **0.078**; `n_subscriptions` (cohort_month=< 2026-01-01) = **2,488**; `rel_diff(early_churn_rate)` = **+20%**
- `h2.c2` → **refuted** (badge `flagged`): `early_churn_rate` (channel=paid_search) = **0.0931**; `n_subscriptions` (channel=paid_search) = **290**; `early_churn_rate` (channel=__rest__) = **0.101**; `n_subscriptions` (channel=__rest__) = **1,010**; `rel_diff(early_churn_rate)` = **-8%**

<details><summary>SQL behind this finding</summary>

```sql
SELECT
    DATE_TRUNC('month', start_date) AS cohort_month,
    COUNT(*) AS n_subscriptions,
    ROUND(
        SUM(CASE WHEN churned_within_90d = TRUE THEN 1 ELSE 0 END)::DOUBLE / COUNT(*),
        4
    ) AS early_churn_rate
FROM saasco_marts.mart_subscription_lifecycle
WHERE start_date >= DATE '2024-01-01'
  AND start_date < DATE '2026-07-01'
GROUP BY DATE_TRUNC('month', start_date)
ORDER BY cohort_month ASC
```

```sql
SELECT
    msl.plan_tier,
    sa.acquisition_channel AS channel,
    COUNT(*) AS n_subscriptions,
    ROUND(
        SUM(CASE WHEN msl.churned_within_90d THEN 1.0 ELSE 0.0 END) / COUNT(*),
        4
    ) AS early_churn_rate
FROM saasco_marts.mart_subscription_lifecycle AS msl
JOIN saasco_staging.stg_accounts AS sa
    ON msl.account_id = sa.account_id
WHERE msl.start_date >= '2025-07-01'
GROUP BY
    msl.plan_tier,
    sa.acquisition_channel
ORDER BY
    msl.plan_tier,
    sa.acquisition_channel
```

#### F4 · The apparent rise in 2026 churn is a mix-shift / small-sample artifact: the account base now has proportionally more starter-plan or monthly-billing accounts (which always churn faster), not a worsening of churn within each cohort.

- **Claim:** `logo_churn_rate` is **no_difference** for plan_tier = `starter` · dimensions: `plan_tier`, `billing_interval`, `month`
- `h4.c1` → **refuted** (badge `clean`): `share_of_total` (plan_tier=starter, month=>= 2026-01-01) = **0.385**; `n_accounts` (plan_tier=starter, month=>= 2026-01-01) = **4,414**; `share_of_total` (plan_tier=starter, month=< 2026-01-01) = **0.408**; `n_accounts` (plan_tier=starter, month=< 2026-01-01) = **7,016**; `rel_diff(share_of_total)` = **-6%**
- `h4.c2` → **untestable** (badge `clean`): could not read period / split_at='2026-01-01' as dates
  - could not read period / split_at='2026-01-01' as dates

<details><summary>SQL behind this finding</summary>

```sql
SELECT
    month,
    plan_tier,
    COUNT(account_id) AS n_accounts,
    COUNT(account_id) * 1.0 / SUM(COUNT(account_id)) OVER (PARTITION BY month) AS share_of_total
FROM saasco_marts.mart_account_months
WHERE
    month BETWEEN DATE '2025-01-01' AND DATE '2026-06-01'
    AND is_churn_month = FALSE
GROUP BY
    month,
    plan_tier
ORDER BY
    month,
    plan_tier
```

```sql
SELECT
    plan_tier,
    billing_interval,
    CASE
        WHEN month < DATE '2026-01-01' THEN 'H2-2025'
        ELSE 'early-2026'
    END AS period,
    COUNT(CASE WHEN is_churn_month = TRUE THEN 1 END) * 1.0 / COUNT(*) AS churn_rate,
    COUNT(*) AS n_account_months
FROM saasco_marts.mart_account_months
WHERE month >= DATE '2025-07-01'
  AND month <= DATE '2026-06-30'
GROUP BY
    plan_tier,
    billing_interval,
    CASE
        WHEN month < DATE '2026-01-01' THEN 'H2-2025'
        ELSE 'early-2026'
    END
ORDER BY
    plan_tier,
    billing_interval,
    period
```
