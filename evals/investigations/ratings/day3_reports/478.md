### Confirmed

#### F1 · Sales-assisted accounts have a meaningfully lower logo churn rate (proportion of churn months) compared to non-sales-assisted accounts.

- **Claim:** `logo_churn_rate` is **lower** for (none) · dimensions: `sales_assisted`
- `h1.c1` → **confirmed** (badge `clean`): `total_account_months` (row=0) = **20,382**; `churn_months` (row=0) = **590**; `churn_rate` (row=0) = **0.0289**; `total_account_months` (row=1) = **15,301**; `churn_months` (row=1) = **537**; `churn_rate` (row=1) = **0.0351**

<details><summary>SQL behind this finding</summary>

```sql
SELECT sales_assisted, COUNT(*) AS total_account_months, SUM(CASE WHEN is_churn_month THEN 1 ELSE 0 END) AS churn_months, ROUND(AVG(CASE WHEN is_churn_month THEN 1.0 ELSE 0.0 END), 4) AS churn_rate FROM saasco_marts.mart_account_months GROUP BY sales_assisted ORDER BY sales_assisted
```

</details>

#### F2 · Sales-assisted accounts have significantly longer average subscription tenure (months active) than self-serve accounts.

- **Claim:** `retention_rate` is **higher** for (none) · dimensions: `sales_assisted`
- `h2.c1` → **confirmed** (badge `clean`): `subscriptions` (row=0) = **1,774**; `avg_months_active` (row=0) = **10.52**; `early_churn_rate` (row=0) = **0.066**; `subscriptions` (row=1) = **1,388**; `avg_months_active` (row=1) = **10.06**; `early_churn_rate` (row=1) = **0.101**

<details><summary>SQL behind this finding</summary>

```sql
SELECT a.sales_assisted, COUNT(sl.subscription_id) AS subscriptions, ROUND(AVG(sl.months_active), 2) AS avg_months_active, ROUND(AVG(CASE WHEN sl.churned_within_90d THEN 1.0 ELSE 0.0 END), 4) AS early_churn_rate FROM saasco_marts.mart_subscription_lifecycle sl JOIN saasco_staging.stg_accounts a ON sl.account_id = a.account_id GROUP BY a.sales_assisted ORDER BY a.sales_assisted
```

</details>

#### F3 · Sales-assisted accounts have a substantially lower early churn rate (churned within # days) than self-serve accounts, suggesting the sales process improves fit from the start.

- **Claim:** `early_churn_rate` is **lower** for (none) · dimensions: `sales_assisted`
- `h3.c1` → **confirmed** (badge `flagged`): `total_subs` (row=0) = **1,774**; `early_churns` (row=0) = **117**; `early_churn_pct` (row=0) = **6.6**; `total_subs` (row=1) = **1,388**; `early_churns` (row=1) = **140**; `early_churn_pct` (row=1) = **10.09**

<details><summary>SQL behind this finding</summary>

```sql
SELECT a.sales_assisted, COUNT(*) AS total_subs, SUM(CASE WHEN sl.churned_within_90d THEN 1 ELSE 0 END) AS early_churns, ROUND(100.0 * SUM(CASE WHEN sl.churned_within_90d THEN 1 ELSE 0 END) / COUNT(*), 2) AS early_churn_pct FROM saasco_marts.mart_subscription_lifecycle sl JOIN saasco_staging.stg_accounts a ON sl.account_id = a.account_id GROUP BY a.sales_assisted ORDER BY a.sales_assisted
```

</details>

#### F4 · Sales-assisted accounts generate substantially higher average MRR per account-month, so the retention benefit is amplified in revenue terms.

- **Claim:** `mrr` is **higher** for (none) · dimensions: `sales_assisted`
- `h4.c1` → **confirmed** (badge `clean`): `avg_mrr` (row=0) = **1,865**; `median_mrr` (row=0) = **1,003**; `accounts` (row=0) = **1,728**; `avg_mrr` (row=1) = **653.9**; `median_mrr` (row=1) = **245**; `accounts` (row=1) = **1,347**

<details><summary>SQL behind this finding</summary>

```sql
SELECT sales_assisted, ROUND(AVG(mrr), 2) AS avg_mrr, ROUND(MEDIAN(mrr), 2) AS median_mrr, COUNT(DISTINCT account_id) AS accounts FROM saasco_marts.mart_account_months GROUP BY sales_assisted ORDER BY sales_assisted
```

</details>

### Suggestive

#### F6 · Sales-assisted accounts have higher average active users throughout their lifecycle, suggesting better product adoption that may contribute to improved retention.

- **Claim:** `usage` is **higher** for (none) · dimensions: `sales_assisted`
- `h6.c1` → **suggestive** (badge `clean`): `avg_active_users` (row=0) = **15.27**; `avg_mrr` (row=0) = **1,867**; `avg_active_users` (row=1) = **6.29**; `avg_mrr` (row=1) = **654.4**

<details><summary>SQL behind this finding</summary>

```sql
SELECT sales_assisted, ROUND(AVG(active_users_avg), 2) AS avg_active_users, ROUND(AVG(mrr), 2) AS avg_mrr FROM saasco_marts.mart_account_months WHERE active_users_avg IS NOT NULL GROUP BY sales_assisted ORDER BY sales_assisted
```

</details>

### Refuted

#### F5 · Refuted: The retention advantage of sales-assisted accounts is NOT explained solely by plan tier composition — sales-assisted accounts show lower churn even within the same plan tier.

- **Claim:** `logo_churn_rate` is **lower** for (none) · dimensions: `sales_assisted`, `plan_tier`
- `h5.c1` → **refuted** (badge `clean`): `churn_rate` (row=0) = **0.0262**; `accounts` (row=0) = **778**; `churn_rate` (row=1) = **0.0311**; `accounts` (row=1) = **485**; `churn_rate` (row=2) = **0.0228**; `accounts` (row=2) = **408**; `churn_rate` (row=3) = **0.0225**; `accounts` (row=3) = **134**; `churn_rate` (row=4) = **0.0377**; `accounts` (row=4) = **584**; `churn_rate` (row=5) = **0.0403**; `accounts` (row=5) = **768**

<details><summary>SQL behind this finding</summary>

```sql
SELECT plan_tier, sales_assisted, ROUND(AVG(CASE WHEN is_churn_month THEN 1.0 ELSE 0.0 END), 4) AS churn_rate, COUNT(DISTINCT account_id) AS accounts FROM saasco_marts.mart_account_months GROUP BY plan_tier, sales_assisted ORDER BY plan_tier, sales_assisted
```

</details>
