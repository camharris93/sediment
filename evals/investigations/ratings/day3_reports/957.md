<details><summary>SQL behind this finding</summary>

```sql
WITH churn_per_account AS (
    SELECT
        account_id,
        MAX(CASE WHEN ended_by = 'churn' THEN 1 ELSE 0 END) AS is_churned
    FROM saasco_marts.mart_subscription_lifecycle
    GROUP BY account_id
),
accounts_enriched AS (
    SELECT
        a.account_id AS account_id,
        a.acquisition_channel AS acquisition_channel,
        CASE WHEN a.region = 'EU' THEN 'EU' ELSE 'non-EU' END AS region_group,
        CASE WHEN YEAR(a.signup_date) = 2024 THEN '2024' ELSE '2025+' END AS cohort_year,
        COALESCE(c.is_churned, 0) AS is_churned
    FROM saasco_staging.stg_accounts AS a
    LEFT JOIN churn_per_account AS c
        ON a.account_id = c.account_id
    WHERE YEAR(a.signup_date) >= 2024
)
SELECT
    ae.region_group,
    ae.acquisition_channel,
    ae.cohort_year,
    COUNT(DISTINCT ae.account_id)                                              AS n_accounts,
    SUM(ae.is_churned)                                                         AS n_churned,
    ROUND(SUM(ae.is_churned) * 1.0 / COUNT(DISTINCT ae.account_id), 4)        AS churn_rate
FROM accounts_enriched AS ae
GROUP BY ae.region_group, ae.acquisition_channel, ae.cohort_year
ORDER BY ae.region_group, ae.acquisition_channel, ae.cohort_year
```

### Refuted

#### F4 · The apparent EU churn spike is a mix-shift artifact: EU's share of new accounts grew rapidly in 2024, so the EU starting base is now larger and even a stable absolute number of churns produces a higher-looking rate; additionally, recent EU cohorts are younger and younger accounts churn at higher base rates.

- **Claim:** `logo_churn_rate` is **higher** for region = `EU` · dimensions: `region`, `derived:tenure_bucket`, `month`
- `h4.c1` → **refuted** (badge `clean`): `eu_account_share` (month=>= 2025-01-01) = **0.298**; `n_total_accounts` (month=>= 2025-01-01) = **29,627**; `eu_account_share` (month=< 2025-01-01) = **0.308**; `n_total_accounts` (month=< 2025-01-01) = **6,056**; `rel_diff(eu_account_share)` = **-3%**
- `h4.c2` → **refuted** (badge `clean`): `churn_rate` (tenure_bucket=1-3) = **0.0282**; `n_account_months` (tenure_bucket=1-3) = **5,954**; `churn_rate` (tenure_bucket=__rest__) = **0.0338**; `n_account_months` (tenure_bucket=__rest__) = **23,673**; `rel_diff(churn_rate)` = **-17%**
- `h4.c3` → **refuted** (badge `clean`): `avg_tenure_at_churn` (region=EU) = **11.06**; `n_churned` (region=EU) = **362**; `avg_tenure_at_churn` (region=__rest__) = **9.823**; `n_churned` (region=__rest__) = **606**; `rel_diff(avg_tenure_at_churn)` = **+13%**

SELECT

```sql
SELECT
    CASE WHEN region = 'EU' THEN 'EU' ELSE 'non-EU' END AS region,
    CASE
        WHEN tenure_month BETWEEN 1 AND 3  THEN '1-3'
        WHEN tenure_month BETWEEN 4 AND 6  THEN '4-6'
        WHEN tenure_month BETWEEN 7 AND 12 THEN '7-12'
        ELSE '13+'
    END AS tenure_bucket,
    COUNT(*)                                                        AS n_account_months,
    COUNT(*) FILTER (WHERE is_churn_month = TRUE)                   AS n_churned,
    COUNT(*) FILTER (WHERE is_churn_month = TRUE) * 1.0 / COUNT(*) AS churn_rate
FROM saasco_marts.mart_account_months
WHERE month >= '2025-01-01'
  AND month <= '2026-06-01'
GROUP BY
    CASE WHEN region = 'EU' THEN 'EU' ELSE 'non-EU' END,
    CASE
        WHEN tenure_month BETWEEN 1 AND 3  THEN '1-3'
        WHEN tenure_month BETWEEN 4 AND 6  THEN '4-6'
        WHEN tenure_month BETWEEN 7 AND 12 THEN '7-12'
        ELSE '13+'
    END
ORDER BY
    region,
    CASE tenure_bucket
        WHEN '1-3'  THEN 1
        WHEN '4-6'  THEN 2
        WHEN '7-12' THEN 3
        WHEN '13+'  THEN 4
    END
```
