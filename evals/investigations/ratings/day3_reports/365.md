#### F4 · The apparent retention benefit of sales-assisted accounts is a mix-shift artifact: sales-assisted accounts are a growing share of newer cohorts that have not yet had enough time to churn, inflating their observed retention.

- **Claim:** `logo_churn_rate` is **no_difference** for sales_assisted = `true` · dimensions: `sales_assisted`, `cohort_month`
- `h4.c1` → **refuted** (badge `self_corrected`): `avg_months_active` (sales_assisted=true) = **10.09**; `account_count` (sales_assisted=true) = **1,347**; `avg_months_active` (sales_assisted=false) = **10.6**; `account_count` (sales_assisted=false) = **1,728**; `rel_diff(avg_months_active)` = **-5%**
- `h4.c2` → **refuted** (badge `clean`): `logo_churn_rate` (sales_assisted=true) = **0.607**; `account_count` (sales_assisted=true) = **244**; `logo_churn_rate` (sales_assisted=false) = **0.498**; `account_count` (sales_assisted=false) = **263**; `rel_diff(logo_churn_rate)` = **+22%**

<details><summary>SQL behind this finding</summary>

```sql
WITH account_sub_avg AS (
    SELECT
        sl.account_id,
        AVG(sl.months_active) AS avg_months_active_per_account
    FROM saasco_marts.mart_subscription_lifecycle AS sl
    GROUP BY sl.account_id
),
account_base AS (
    SELECT
        a.account_id,
        DATE_TRUNC('quarter', a.signup_date) AS cohort_quarter,
        CASE WHEN a.sales_assisted THEN 'true' ELSE 'false' END AS sales_assisted_label,
        asa.avg_months_active_per_account
    FROM saasco_staging.stg_accounts AS a
    LEFT JOIN account_sub_avg AS asa
        ON a.account_id = asa.account_id
),
cohort_totals AS (
    SELECT
        ab.cohort_quarter,
        COUNT(DISTINCT ab.account_id) AS total_accounts_in_cohort
    FROM account_base AS ab
    GROUP BY ab.cohort_quarter
)
SELECT
    ab.cohort_quarter,
    ab.sales_assisted_label AS sales_assisted,
    COUNT(DISTINCT ab.account_id) AS account_count,
    AVG(ab.avg_months_active_per_account) AS avg_months_active,
    ROUND(
        COUNT(DISTINCT ab.account_id) * 1.0 / ct.total_accounts_in_cohort,
        4
    ) AS sales_assisted_share
FROM account_base AS ab
JOIN cohort_totals AS ct
    ON ab.cohort_quarter = ct.cohort_quarter
GROUP BY
    ab.cohort_quarter,
    ab.sales_assisted_label,
    ct.total_accounts_in_cohort
ORDER BY
    ab.cohort_quarter,
    ab.sales_assisted_label
```

```sql
SELECT

    COUNT(DISTINCT CASE WHEN is_churn_month THEN account_id END) * 1.0
        / COUNT(DISTINCT account_id) AS logo_churn_rate
FROM saasco_marts.mart_account_months
WHERE cohort_month < '2024-07-01'
GROUP BY CASE WHEN sales_assisted THEN 'true' ELSE 'false' END
ORDER BY sales_assisted
```
