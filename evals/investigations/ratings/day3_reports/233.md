<details><summary>SQL behind this finding</summary>

```sql
SELECT
  DATE_TRUNC('month', s.start_date) AS cohort_month,
  COUNT(*) AS total_subscriptions,
  SUM(CASE WHEN s.churned_within_90d THEN 1 ELSE 0 END) AS early_churned,
  ROUND(100.0 * SUM(CASE WHEN s.churned_within_90d THEN 1 ELSE 0 END) / COUNT(*), 2) AS early_churn_pct
FROM saasco_marts.mart_subscription_lifecycle s
JOIN saasco_staging.stg_accounts a ON s.account_id = a.account_id
WHERE a.signup_date >= '2025-01-01' AND a.signup_date < '2026-01-01'
GROUP BY 1
ORDER BY 1
```

<details><summary>SQL behind this finding</summary>

```sql
SELECT
  s.ended_by,
  ROUND(AVG(s.failed_attempts_before_end), 3) AS avg_failed_attempts,
  COUNT(*) AS n_subscriptions
```

#### F4 · Price sensitivity ('too_expensive') and missing features are the top self-reported cancel reasons for 2025-cohort churned accounts.

- **Claim:** `logo_churn_rate` is **higher** for cohort_year = `2025` · dimensions: `cancel_reason`
- `h4.c1` → **confirmed** (badge `flagged`): `churned_subscriptions` (row=0) = **197**; `pct_of_churned` (row=0) = **47.36**; `churned_subscriptions` (row=1) = **102**; `pct_of_churned` (row=1) = **24.52**; `churned_subscriptions` (row=2) = **86**; `pct_of_churned` (row=2) = **20.67**; `churned_subscriptions` (row=3) = **31**; `pct_of_churned` (row=3) = **7.45**

<details><summary>SQL behind this finding</summary>

```sql
SELECT
  ss.cancel_reason,
  COUNT(*) AS churned_subscriptions,
  ROUND(100.0 * COUNT(*) / SUM(COUNT(*)) OVER (), 2) AS pct_of_churned
FROM saasco_staging.stg_subscriptions ss
JOIN saasco_staging.stg_accounts a ON ss.account_id = a.account_id
WHERE a.signup_date >= '2025-01-01' AND a.signup_date < '2026-01-01'
  AND ss.status = 'canceled'
  AND ss.cancel_reason IS NOT NULL
GROUP BY 1
ORDER BY 2 DESC
```

</details>
